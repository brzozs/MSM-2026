# PROJECT OVERVIEW
- Application Name: Undecided (Propose 5 strong, memorable technical/consumer names, e.g., VectorCast, FlywayTick, IxodesRadar)
- Core Purpose: A zero-cost, real-time predictive ecological and public health web application centered around an **interactive, full-screen 3D/2D global heatmap background** on the landing page. Because individual ticks cannot be tracked in flight, the platform models and visualizes the **Avian Influx, Stopover Drop, Questing Microclimate, and Community Pathogen Impact Index**—combining live bird migration telemetry, weather-forced avian stopover triggers, citizen science tick sightings, microclimate questing conditions, and regional pathogen prevalence overlaid on human population density.
- Target Audience: 
  1. Everyday consumers, hikers, pet owners, and outdoor workers looking for an intuitive, visually compelling live radar of tick questing and avian influx warnings.
  2. County public health departments, researchers, and veterinary clinics monitoring emerging vector-borne pathogen fronts (Lyme, Powassan virus, Babesiosis, Alpha-gal, Anaplasmosis, Tick-Borne Encephalitis) and community health impacts.

# TECHNICAL CONSTRAINTS & STACK ($0 BUDGET ARCHITECTURE)
- Frontend & Interactive Global Canvas: 
  - React 19 (Vite or Next.js static/SSR on Vercel Free Tier), TypeScript, Tailwind CSS (glassmorphic floating HUD controls, layer toggles, and time-scrubber bar overlaid on the full-screen map).
  - Geospatial WebGL Rendering Engine (100% Free / No API Key Billing): **MapLibre GL JS** (supporting both 3D Globe projection and flat Mercator) interleaved with **Deck.gl** (`HeatmapLayer`, `TripsLayer` / custom WebGL particle advection for bird migration trajectories, `H3HexagonLayer` for unified multi-resolution spatial indexing, `ContourLayer` for pathogen frontiers, and `PolygonLayer` for regional health boundaries) + **OpenFreeMap** or **Protomaps (PMTiles hosted on Cloudflare R2)** for zero-cost dark-mode vector basemaps.
- Backend / API: Python (FastAPI) deployed on Render Free Tier, Koyeb Free Tier, or Cloudflare Workers for core REST endpoints, dynamic spatial queries, and ecological risk modeling.
- Scheduled ETL & Scraping Workers ($0 Compute): GitHub Actions scheduled cron workflows (generating pre-computed global Uber H3 hex grids and GeoJSON/FlatGeobuf/PMTiles snapshots every 3–6 hours) + Upstash Redis (Free Tier) for rate-limit state.
- Database & Edge Storage ($0 Tier): 
  - Supabase (Free Tier PostgreSQL + PostGIS extension for spatial joins/polygon intersections, plus Supabase Auth for JWT/RBAC).
  - Cloudflare R2 (Free 10GB/month with zero egress fees) serving pre-computed static vector tiles (`.pmtiles`), H3 hexagonal JSON grids, and hourly/daily heatmap payloads directly to the React frontend via CDN so the global background map loads instantaneously in <100ms without waking or exhausting the database.
- External Services & Data Sources (Strictly Free & Legally Permissive):
  1. Global Host Migration & Ground-Foraging Guilds: 
     - eBird API 2.0 (Global real-time sightings specifically filtered for **ground-foraging migratory passerine guilds** known to carry high larval/nymphal tick loads: thrushes, robins, song sparrows, towhees, ovenbirds, wrens).
     - NOAA NEXRAD Level II/III Open Data on AWS S3 & ENRAM (European Network for the Radar Surveillance of Animal Movement) open repository (public domain/CC0 weather radar vertical profiles of nocturnal bird migration velocity, altitude, and density).
     - Movebank API (CC0 live and archival global bird/mammal GPS telemetry tracks).
  2. Global Tick Sightings & Vector Density: 
     - iNaturalist API (Global near-real-time geotagged tick observations across *Ixodes*, *Amblyomma*, *Dermacentor*, *Rhipicephalus*, and *Haemaphysalis* genera).
     - GBIF API & VectorMap / Walter Reed Biosystematics Unit (WRBU) (Global CC0/CC-BY baseline tick distribution and museum/field occurrences).
  3. Microclimate Questing & Avian "Fallout/Stopover" Triggers: 
     - Open-Meteo Global API (Free, no key required; provides both **Tick Questing Metrics** [soil temperature >7°C, soil moisture, relative humidity >82%, Vapor Pressure Deficit] and **Avian Stopover/Fallout Triggers** [precipitation, low cloud ceiling, and opposing headwinds that force nocturnal migrating birds to land and drop engorged ticks]).
     - ESA WorldCover 10m / NASA MODIS NDVI (Free static/seasonal raster baselines pre-indexed into H3 hexagons to weight canopy cover, forest edge ecotone, and leaf-litter suitability where dropped ticks survive).
  4. Pathogen Spread & Community Health Impact:
     - US CDC ArboNET & Tick Surveillance (`data.cdc.gov` Socrata API), CDC Tick Bite Data Tracker (weekly emergency department visits by region), and NEON API (NSF-funded CC0 drag-cloth tick abundance by life stage & PCR pathogen testing).
     - State DOH Open Data Portals (e.g., NY State `health.data.ny.gov` Socrata API for county-level tick collection and PCR pathogen rates).
     - ECDC (European Centre for Disease Prevention and Control) Surveillance Atlas & Vector Maps (open access European tick and TBE/Lyme distribution data).
  5. Human Population & Community Vulnerability Baselines:
     - US Census TIGER/Line & WorldPop / GHSL (Global Human Settlement Layer) open population density grids (pre-aggregated into H3 hexagons to calculate actual human exposure and community health impact when a high-risk tick influx intersects populated suburban/urban green spaces).
